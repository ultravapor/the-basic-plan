# 더베이직플랜 마스터 전략 (v1.0)

> 이 문서는 이 저장소의 **최상위 판단 기준**이다. 작업 전에 이 문서를 먼저 읽고,
> SEO·AEO·GEO·디자인 트렌드·일반 마케팅 관행보다 이 문서의 원칙을 우선한다.

## 0. 한 문장

병원 마케팅을 더 하기 전에, 환자가 어디서 멈추고 있는지부터 확인한다.

## 1. 지금 단계의 목표

사이트를 "완성"하는 것이 아니라, **고객 반응을 받아 다음 상품을 발견할 수 있는
실험 가능한 상태**를 만든다. 완성형 월정액 상품을 지금 고정하지 않는다.

- 최우선(MVO): `병원 유입·전환 점검`을 실제로 판매하고 검증할 수 있는 상태.
- 판단 기준: 이 사이트는 "우리를 믿으라"고 말하는가, 아니면 **방문자가 자기 병원 문제를
  스스로 점검하다가 우리에게 한번 물어볼 이유를 발견하게** 만드는가? — 항상 후자.

## 2. 첫 고객(ICP)

개원 2~7년차, 비급여 비중 높은 과(피부·성형·치과 등) 원장. 이미 월 100~500만 원을
마케팅에 쓰는데 신규 문의가 정체/감소. 대행사에 1~2번 데여 마케팅 자체를 불신하기 시작.

- 핵심 Job: **통제감 회복** — 내 유입을 내가 이해하고 판단할 수 있는 상태.
- 3대 불안: ① 불확실성(뭐 때문에 오는지 모름) ② 정보 비대칭(대행사 말 검증 불가)
  ③ 기회손실 공포(경쟁병원은 뭔가 하는 듯).
- 최대 공포: **또 판매당하는 것.**

## 3. 포지셔닝

"AEO/GEO 업체"도 "종합대행사"도 아니다.
→ **뭘 더 팔기 전에, 우리 병원에서 뭐가 되고 있고 뭐가 새는지 먼저 찾아주는 독립적 시선.**
상품의 뼈대는 진단 → 우선순위 → 실행 → 측정. 블로그·플레이스·홈페이지·AEO/GEO는
그 아래 실행 수단일 뿐이다.

## 4. 환자 획득 여정 (모든 점검·콘텐츠의 공통 축)

발견 → 관심 → 비교 → 문의 → 응대 → 예약. 각 단계가 다음으로 이어져야 신환이 된다.
점검은 이 여정에서 **어디가 병목인지**부터 찾는다. 처음부터 해결책을 정하지 않는다.

## 5. 콘텐츠·카피 원칙

1. **AEO/GEO는 주인공이 아니다.** "AI 시대!"로 시작하면 "팔려고 겁주네"로 반발한다.
   불안을 키우는 배경으로만 등장시키고, 진입은 "문의가 줄었다면"으로 연다.
2. **"안 사도 됩니다"가 신뢰다.** "이건 하세요"보다 "이건 지금 돈 쓸 필요 없습니다"가
   더 강한 신뢰 신호. 실제로 어떤 결론이 가능한지 보여준다.
3. **질문을 바꾸는 게 목적.** "우리한테 맡기세요"가 아니라, 고객 질문을
   "마케팅이 왜 안 되지?"에서 "우리 유입의 어디가 막혔지?"로 옮긴다.
4. **추상어 금지.** "데이터 기반/맞춤형/철저한 관리" 같은 말은 "그래서 실제로 무엇을
   하는가"가 붙지 않으면 관찰 가능한 행동으로 바꾼다.
5. **AI 티 금지.** 볼드(**) 남발하지 않는다. 근거 없는 숫자·확률·"유일한/반드시/무조건"을
   쓰지 않는다.

## 6. 약속할 수 있는 것 / 없는 것

- 약속하지 않는다: 특정 검색 순위·신규환자 수·매출·AI 추천·무조건적 전환율 상승.
- 약속한다: 무엇이 관찰되는지 / 어떤 병목이 우선인지 / 왜 그렇게 판단했는지 /
  무엇을 먼저 하고 무엇은 지금 안 해도 되는지 / 이후 어떤 지표를 볼지.
- 결과를 장담하는 대신 **판단 근거가 남도록** 한다.

## 7. 절대 하지 말 것

- 메인 상품을 지금 완성형 월정액으로 고정. GEO/미스터리콜 전문회사로 재포지셔닝.
- "모든 것을 해결"식 범위 과장. 없는 포트폴리오·가상 사례를 실제처럼 표현. 성과 보장.
- 이유 없는 전면 재작성. 기존 AEO/GEO 자산 무조건 삭제. 디자인 변경만으로 문제 해결.
