# 더베이직플랜 콘텐츠 기획·발행 규칙 v1

> 이 문서는 문체 지침이 아니라 **무엇을·왜·어떤 순서로 발행할지**를 정하는 규칙이다.
> 개별 글을 쓰기 전에 이 규칙을 먼저 적용한다. 사업 최상위 기준은 [master-strategy.md](master-strategy.md),
> 문장/판단 포맷은 [content-writing-template.md](content-writing-template.md)와 함께 본다.

## 1. 핵심 세계관
"더 데려오기 전에, 지금 들어온 환자가 어디에서 빠지고 있는지부터 본다."
경쟁이 (노출→순위→광고→콘텐츠 추가)에 집중한다면, 우리는 유입→첫인상→정보 탐색→비교→신뢰→문의→상담→예약
전체에서 **환자의 의사결정이 어디서 멈추는지**를 본다.
반복 증명할 메시지: "숫자를 보지 말라는 게 아니라, 숫자 뒤에서 환자가 어떤 판단을 하는지 함께 봐야 한다."

## 2. 만들고 싶은 독자 정체성
목표는 "더베이직플랜 팬"이 아니라, 독자가 스스로를 이렇게 느끼게 하는 것:
"나는 조회수·상위노출만 보는 원장이 아니라, 환자가 어떤 과정을 거쳐 병원을 선택하는지 보는 원장이다.
대행사 보고서를 그대로 받기보다 성과를 스스로 판단할 줄 아는 원장이다."
콘텐츠를 읽는 행위가 "마케팅을 제대로 판단하고 싶은 원장"이라는 정체성을 강화해야 한다.

## 3. 팬 생성 모델 (플라이휠)
Discovery → Identification → Participation → Propagation → 새로운 사람의 Discovery
- **Discovery(발견)**: 무관심한 사람이 자발적으로 두 번째 행동(다음 글·프로필·다른 콘텐츠)을 하게. 반응 목표: "어? 이렇게 생각해본 적 없는데."
- **Identification(동일시)**: 여러 글에서 반복 패턴 발견 → "이 사람은 항상 이렇게 문제를 보는구나" → "나도 이렇게 생각하는 게 맞는 것 같다."
- **Participation(참여)**: 관점을 직접 사용(자기 병원 숫자 확인·응대 청취·체크리스트·공유). 읽는 콘텐츠 → 해보는 콘텐츠.
- **Propagation(전파)**: 다른 원장에게 관점을 전달("조회수보다 어디서 빠지는지를 봐야 한다더라").

## 4. 팬 생성 ≠ 구매 과정 (둘 다 동시 관리)
구매 6단계(= 우리 doubt H1~H6): 1 필요성(H1) · 2 상품(H2) · 3 판매자(H3) · 4 증거(H4) · 5 자기판단(H5) · 6 구매후 위험(H6).
팬 생성은 "이 사람 생각을 계속 보고 싶다", 구매는 "내 문제를 맡겨도 된다".
초기 콘텐츠는 팬 생성 비중↑, 상담에 가까워질수록 구매 6단계 불확실성 제거.

## 5. 글의 기본 설계 원칙
모든 글은 "읽기 전과 후 독자가 무엇을 다르게 보게 되는가"에서 시작. 글 하나 = 하나의 **인식 변화**.
구조: 기존 믿음 → 비대칭(다른 관점) → 중요성 → 판단 기준(자기 병원에서 확인법) → 다음 질문 → 다음 콘텐츠(내부링크).

## 6. 주제 선정 공식 (검색량만으로 발행 안 함)
동시에 만족: ① 문제 범위가 넓다(많은 원장이 겪음) ② 관점이 좁고 독특하다(넓은 문제 × 독특한 해석)
③ 정체성과 연결된다("이런 걸 체크할 줄 아는 원장이 되고 싶다") ④ 다음 질문이 존재한다 ⑤ 실제 행동으로 연결(숫자·화면·전화·검색·비교·체크리스트).

## 7. 사이트 카테고리 (기존 구조 우선, 새 route 임의 생성 금지)
기존 `/posts/`(인사이트) 유지. 내부 `category` 메타로 5분류를 관리(전부 상단 메뉴에 노출할 필요 없음):
- **A. 마케팅 누수 진단** — 가장 넓은 입구, "성과가 이상하다" 원장 대상. 목적: Discovery.
- **B. 환자의 의사결정** — 환자가 병원을 어떻게 판단하는지. Identification의 중심.
- **C. 채널과 전환 구조** — 블로그·홈페이지·플레이스·전화·SNS를 환자 여정의 한 단계로 해석.
- **D. 성과와 대행사 검증** — 원장이 스스로 판단할 기준 제공. 정체성 강화 + 판매자 검증.
- **E. AI 검색과 변화** — 뉴스 요약이 아니라 "환자의 발견·선택이 어떻게 변하는가".

## 8. 1차 발행 순서 (SEO 키워드 묶음이 아니라 세계관 이해 순서)
**PHASE 1 — "문제를 다르게 보는 사람" 인식**
1. 조회수는 늘었는데 신규환자는 줄었다면, 유입부터 의심하면 안 되는 이유 (A · 조회수→환자여정)
2. 문의는 오는데 예약이 안 잡힌다면 광고비보다 먼저 확인할 것 (A · 광고성과→문의 이후 과정)
3. '더 데려오는 것'보다 먼저 해야 할 일 (A · 유입보다 누수 선언)
4. 검색 1위인데도 환자가 결정하지 못하는 병원 블로그 (C · 상위노출≠의사결정)
5. 병원 홈페이지 방문자는 병원을 공부하러 들어오지 않는다 (B · 첫 화면에서 빠르게 판단)
6. 가격을 물어보고 사라진 환자, 정말 가격 때문일까 (B · 표면 행동 vs 실제 의사결정)

**PHASE 2 — 같은 렌즈를 여러 문제에 반복 (Confirmation)**
7. 지역 키워드를 계속 늘려도 신규환자가 늘지 않는 이유
8. 시술 효과만 자세히 설명하는 글이 예약을 만들지 못하는 이유
9. 환자는 병원 콘텐츠를 읽으며 무엇을 확인하고 있을까
10. 네이버 플레이스에 들어온 환자는 이미 무엇을 비교하고 있을까
11. 전화 한 통이 광고보다 중요해지는 순간
12. 좋은 후기가 많은데도 환자가 망설이는 이유
(모든 결론은 "환자가 다음 단계로 넘어갈 판단 재료가 충분한가"로 수렴)

**PHASE 3 — 원장이 스스로 판단(Participation 강화)**
13. 병원 마케팅 보고서에서 조회수보다 먼저 봐야 할 숫자
14. 대행사를 바꾸기 전에 먼저 확인해야 할 5가지
15. 마케팅이 잘되고 있는지 원장이 직접 판단하는 방법
16. 우리 병원은 어디에서 환자를 놓치고 있을까: 환자 여정 점검표 (★ 읽는 글이 아니라 직접 점검. 향후 체크리스트/인터랙티브 진단으로 발전)

**PHASE 4 — 새 환경에도 같은 세계관** (항상 기술변화→발견 변화→의사결정 변화→병원이 준비할 것 순)
17. AI가 우리 병원을 소개해줘도 예약은 대신 만들어주지 않는다
18. AI 검색 시대에도 결국 환자가 확인해야 하는 것은 남는다
19. AEO·GEO를 시작하기 전에 병원이 먼저 정리해야 할 것
20. 네이버 검색이 바뀌면 정말 바뀌어야 하는 것은 무엇일까

## 9. 내부링크 = '관련 글'이 아니라 사고의 순서
모든 신규 글은 최소 **이전 사고 단계 글 + 다음 사고 단계 글**을 정의한다.
예: 조회수는 늘었는데 신규환자는 줄었다면 → 문의는 오는데 예약이 안 잡힌다면 → 전화 한 통이 광고보다 중요해지는 순간 → 우리 병원은 어디에서 환자를 놓치고 있을까.

## 10. CTA는 단계별로 다르게 (서비스 먼저 내세우지 않음)
- Discovery: 다음 관점을 읽게. ("유입이 문제가 아니라면 다음은 문의 이후 과정입니다.")
- Identification: 스스로 확인하게. ("최근 한 달 유입→문의→예약 숫자를 한 줄로 적어보세요.")
- Participation: 체크리스트·자가진단·비교 제공.
- Purchase: 그 이후 상담 연결. ("직접 판단이 어렵다면 함께 점검합니다.")
항상 정보 → 판단 → 행동 → 서비스 순서.

## 11. 제목 공식
익숙한 현상 + 예상 밖 결과 + 새로운 판단 기준. ("조회수가 늘었는데" + "신규환자는 줄었다면" + "유입부터 의심하면 안 되는 이유")
"우리도 그런데?"와 "왜 그렇지?"를 동시에 일으킨다. 자극 자체가 목표는 아니다.

## 12. 발행 금지 기준
- 키워드만 바꾼 글(병원/피부과/성형외과 블로그 마케팅 — 인식 변화가 같으면 별도 글 X).
- 누구나 할 수 있는 말("꾸준한 콘텐츠가 중요합니다").
- 정보는 있지만 관점("그래서 무엇을 다르게 판단?")이 없는 글.
- 다음 행동(질문/콘텐츠/확인)이 하나도 없는 글.
- 자기 자랑 중심 글("우리는 잘합니다" → "이걸 확인하는 게 중요합니다, 그래서 우리는 이렇게 확인합니다" 순서).

## 13. 콘텐츠 기획 메타데이터 (frontmatter, 비노출)
`category`(A~E) · `core_problem` · `old_belief` · `new_belief` · `fan_stage`(discovery/identification/participation/propagation) ·
`purchase_stage`(= doubt H1~H6) · `identity_message` · `reader_action` · `previous_article` · `next_article` · `primary_cta` · `evidence_required`.
**모든 글 필수 3종: `old_belief`, `new_belief`, `identity_message`.** (구현: `src/content.config.ts`)

## 14. 신규 주제 우선순위 (검색량보다 우선)
① 자주 겪는 문제인가 ② "우리도 그런데?" 자기관련성 ③ 기존 상식과 다른 관점 ④ 세계관 강화 ⑤ 직접 확인·행동 가능 ⑥ 다음 콘텐츠로 연결 ⑦ 구매 6단계 중 하나 이상의 의심 감소.
검색량이 커도 위를 거의 못 채우면 후순위, 작아도 인식 변화가 크면 발행.

## 15. 팬의 범위를 넓히는 원칙
보편적으로 큰 문제 × 독특한 해석. 너무 좁은 정체성("나는 AEO 잘 아는 원장") 대신 넓고 강한 정체성("나는 환경이 바뀌어도 환자가 병원을 선택하는 구조를 보는 원장").

## 16. 최종 사이트 경험 (순서)
1글 "이런 관점 처음인데" → 2글 "우리 병원도 봐야겠는데?" → 3글 "이 사람은 항상 환자가 어디서 판단을 멈추는지 보는구나" → 여러 글 후 "이렇게 생각하는 게 맞는 것 같다" → "우리 병원도 이 기준으로 점검하고 싶다" → "혼자 어렵다면 이 사람에게 봐달라 할 수 있겠다."

## 17. Claude Code 실행 규칙 (발행 전 체크)
1. 기존 콘텐츠와 중복 확인 2. 현재 route·category 확인 3. 기존 URL 불필요 변경 금지 4. 기존 디자인 재사용
5. 동일 주제 있으면 새 글보다 보강·내부링크 우선 6. `old_belief/new_belief/identity_message` 먼저 정의
7. 팬 단계·구매 단계 위치 정의 8. 이전 글·다음 글 결정 9. 그 뒤 원고 작성 10. 발행 후 sitemap·내부링크 확인.
원페이지 랜딩은 무리하게 재구축하지 않음. 5개 카테고리를 전부 상단 메뉴에 넣지 않음.

## 18. 사실 검증 규칙
AI 출력은 초안. 발행 전 확인 필수 항목: 네이버 검색·플레이스 변화 / AI 검색·브리핑 / AEO·GEO 기능 / 의료광고 법령·심의 / 통계 / 플랫폼 정책 / 실제 사례 수치 / 연구.
우선순위: 공식 발표·법령·플랫폼 문서 → 원문 연구 → 신뢰 전문자료 → 언론 → 2차 콘텐츠. 확인 못 한 수치·주장은 단정하지 않음.

## 19. 가장 중요한 최종 원칙
콘텐츠 수가 목표가 아니다. 모두 쌓였을 때 하나의 일관된 생각을 만든다:
"병원 마케팅은 더 많이 데려오는 기술만이 아니라, 환자가 발견부터 예약까지 무엇을 보고·의심하고·어디서 멈추는지를 설계하는 일이다."
그리고 더베이직플랜은 **그 과정에서 어디가 막혀 있는지 찾아내는 사람**으로 기억되어야 한다.

## 키워드 의도 전략 (2026-10-24, 대표 학습 반영)

> ⚠️ 이것은 **발행 축(1~4: 기존기획안/카페질문/페르소나/세계관)을 대체하지 않는다.** 축 1~4 = 글의 출처·관점(어디서 주제가 나오나), **축 5~7 = 그 글이 겨냥하는 검색 의도(키워드 속성)**. **서로 직각(orthogonal)인 두 차원**이며, 한 글은 1~4 중 하나 + 5~7 중 하나를 가진다. 예: "피부과 블로그 효과"=축2(카페질문) × 축6(문제인식). 기존 축 1~4는 그대로 유지.

노출이 아니라 **문의(전환)로 이어지는 키워드**를 겨냥한다. 검색어를 구매의도로 3분류(축 5~7)하고, 글 기획 시 어디에 속하는지 먼저 판단한다.

| 축 | 의도 | 전환 | 방침 |
|---|---|---|---|
| **축5** | **개념학습** (AEO·GEO 뜻, AI 검색이란) | 낮음 | 지양. GEO/브랜딩용만. 에세이 각도 상당수가 여기 — 전환 기대 X. |
| **축6** | **문제인식** (피부과 블로그 효과 없는 이유, 광고비 올렸는데 신환 그대로, 플레이스 상위인데 전화 안 옴) | 높음 | **최우선 진입점.** 구매 직전 수요 + 신생 브랜드도 이길 수 있음. 진료과 특정(피부과/치과)으로 좁히면 상업성↑. |
| **축7** | **업체탐색** (대행업체 고르는 법, 마케팅 비용, 대행사 바꾸는 기준) | 최고 | 선별 공략. 경쟁·검색량 낮음 주의. 축3 대행사 판단 글이 사실상 여기 대응. |

- 신생 브랜드 공략 순서: **개념학습 버림 → 문제인식부터 → 업체탐색 선별.**
- 병원 마케팅 B2B 키워드는 ICP가 좁아 검색량 자체가 얇다(네이버 자동완성으로 확인). 그래서 각 방문자가 고가치이며, 검색 유입만으로는 한계 → 네이버 교차발행 병행 필수.
- AI 인용을 노리면 "잘 쓴 글"이 아니라 **인용할 구체 사실**(검증 가능한 수치·기준·절차)을 넣는다. 단 보장·근거없는 숫자 금지 — 가짜 성공사례 수치(경쟁사 방식) 베끼지 말 것. 우리의 구체성 = 실제 진단 데이터·검증 가능 기준.

## 발행 플랜 v2 — 상위노출 우선 전환 (2026-10-29, 대표 지시)

> 대표 지시: **더베이직플랜 채널은 "유의미한(실수요) 키워드에서의 상위노출"을 최우선으로 한다.**
> 이 섹션이 "무엇을·어떤 순서로 발행할지"의 **최상위 규칙**이다. 기존 축(1~7)과 세계관(1~19조)은 폐기하지 않는다 —
> 축은 이제 "어떤 목소리/관점으로 쓰나(HOW)"를 정하고, **키워드 클러스터가 "무엇을·어떤 순서로(WHAT/WHEN)"를 정한다.**

### v2-1. 왜 바꿨나 (데이터 근거)
GSC 3개월(~2026-10): 총 노출 35, 비브랜드 실수요 노출은 "병원 마케팅 성공 사례" 1건 @ 58위.
저수요·에세이형 키워드는 잘 걸리지만(평균순위 7.8을 만든 숨은 쿼리) 노출수 자체가 미미하고,
head 상업 키워드(피부과 마케팅/병원 마케팅 대행)는 대형 대행사가 점령 → 신생 사이트는 58위.
**결론: "좋은 글"이 아니라 "신생 사이트가 실제로 이길 수 있는, 수요 있는 키워드"를 골라야 상위노출이 난다.**

### v2-2. 승률 매트릭스 (네이버 자동완성 실조사, 2026-10-29)

| **병원 블로그(작성법·심의·신고·대행)** | 높음(자동완성 10) | 중하 | **상** | **2순위 클러스터** |

### v2-3. 전술 = 클러스터 지배 (pillar + spoke)
head 상업어에서 바로 이기려 하지 않는다. **좁은 토픽 클러스터를 먼저 장악 → 토픽 권위 축적 → head로 확장.**
- 글 1편 = **자동완성에 실재하는 롱테일 키워드 1개**를 제목·H2·answer에 정확히 반영(= 검색 의도 1:1 매칭).
- 같은 클러스터 글끼리 내부링크로 묶어 pillar(총정리) ↔ spoke(세부) 구조를 만든다.
- 클러스터가 포화되면 다음 클러스터로 이동.

### v2-6. 새 "큐 제작" 규칙 (v1의 축1+축3 2편 규칙을 이 채널에선 대체)
"큐 제작"/"다음 큐" 요청 시 → **현재 1순위 클러스터의 다음 갭 2편**을 미래 pubDate로 작성.
- 각 글은 타깃 키워드 1개를 명확히 겨냥(제목·answer·H2에 반영).
- 목소리(축)는 자동 결정: 심의/절차 정보형 = 축1(실무)·discovery, 대행 맡길까류 = 축3/축7.
- 1순위 포화 → 2순위(병원 블로그) → 3순위(진료과). build→check:seo→commit→push, 크론 자동노출은 동일.
- 축2(카페질문)는 대표가 질문 주면 우선 끼워넣되, 가능하면 실수요 키워드에 매핑.

### v2-7. 측정 = 증명 (순위가 KPI)
이제 증명 지표는 "글 품질"이 아니라 **1순위 클러스터 키워드의 실제 순위**다.
- 추적 키워드: 의료광고 심의 대상 / 신청방법 / 심의필 / 유효기간 / 면제 등(실수요 확인된 것).
- 기준선: 현재 대부분 미노출. 목표: 4~8주 내 **네이버·구글에서 top-10 진입**.
- top-10 진입 = 실수요 + 상위노출 동시 달성 = 엔진 작동 증명. 여기서 되면 head 상업어로 확장.
- 여전히 노출 0이면 병목은 키워드가 아니라 권위·배포 → 네이버 교차발행으로 전환.

### v2-8. 바뀌지 않는 것
문체(한 문장 한 줄, 볼드 남발·AI 티 금지), 보장 금지, 근거 없는 수치 금지, 의료·법률 사실검증(18조),
가짜 성공사례 금지, 내부링크=사고의 순서, CTA 단계(정보→판단→행동→서비스). 세계관 1~19조는 글의 "관점"으로 계속 적용.

## 발행 플랜 v2.1 — 전환 필터 + 매일 4편 체제 (2026-10-30, 대표 지시)

> 대표 지시 2건: (1) **"의료광고 심의 클러스터는 노출돼도 전환이 약하니 패스."** (2) **"기존 플랜 유지 + 새 제안 2개 동시 발행 = 매일 4편. 선정 기준은 경쟁 낮고 전환 높은 것(수요는 다소 후순위)."**
> v2-4~v2-7을 이 섹션이 갱신한다. v2-1~v2-3(승률 매트릭스·클러스터 지배 원리)은 유효.

### v2.1-A. 전환 필터 추가 (이중 필터)
키워드는 이제 **두 관문**을 동시 통과해야 발행한다.
1. **신생 승률** = 수요 있고 × 경쟁 낮음(대행사가 글 안 쓰는 정보형/버티컬 롱테일).
2. **전환 의도** = 검색자가 "우리를 쓸 사람"인가(업체탐색·대행·제작 > 단순 정보/컴플라이언스).
→ **의료광고 심의**: 승률 높지만 전환 약함 → **패스.** 기존 2편(clinic-blog-medical-ad-review-checklist, how-to-get-medical-ad-review)은 삭제하지 않고 **GEO/E-E-A-T 자산으로만 유지**, 더 확장 안 함.

### v2.1-B. 데이터가 말하는 트릴레마 (받아들일 전제)
{수요 많음 × 전환 높음 × 경쟁 낮음}을 동시에 주는 키워드는 이 B2B 니치에 **없다.**
전환 키워드(업체탐색)는 수요가 얇다("피부과 마케팅 업체" 자동완성 0). 그래서 **상위노출을 다 먹어도 검색 단독 리드 상한은 낮다.** 상위노출 = "엔진 작동" 증명 가치. 볼륨 레버는 결국 배포(네이버 교차발행·직접영업) — 플랜의 전제로 둔다.

### v2.1-C. 매일 4편 체제 (2026-11-07 시작)
기존 큐(1편/일, ~11/6)는 그대로. **11/7부터 매일 4편**, 다음 4트랙 각 1편:
| 트랙 | 성격 | 선정 기준 |
|---|---|---|
| **① 축1 (기존 기획안)** | 실무 + '노출 말고 전환' 세계관 | 기존 유지 |
| **② 축3 (페르소나 H1~H6)** | 데인 원장 의심 제거(반론의 사다리) | 기존 유지, doubt 순환 |
| **③ 동물병원 비치헤드 (신규)** | 수의사 출신 E-E-A-T 독점 구간 | 저경쟁 × 고전환 |
| **④ 대행/제작 "고르는 법" (신규)** | 채널·업체 선택 전환 롱테일 | 저경쟁 × 고전환 |

"큐 제작"/"다음 큐" = **다음 빈 날짜 하루치 4편(①②③④ 각 1편)**. build→check:seo→commit→push, 크론 자동노출 동일.

### v2.1-D. 신규 트랙 키워드 백로그 (전환형, 소진 순서)
**③ 동물병원:** 동물병원 마케팅 업체 고르는 법 / 회사·업체·대행사 뭘 보고 맡기나 / 동물병원 개원 마케팅 준비 / 동물병원 블로그 직접 vs 대행 / 동물병원 홈페이지 필요할까 / (기둥)수의사가 본 동물병원 마케팅의 진짜 차이.
**④ 대행·제작 고르는 법:** 병원 블로그 대행사 고르는 법 / 블로그 관리 대행 맡길까 직접 할까 / 홈페이지 제작 업체 고르는 법 / 블로그 체험단 맡겨도 될까 / 대행 비용 뭘 기준으로 보나 / 처음 맡길 때 뭘 물어봐야 하나.
※ §12 준수: 키워드만 바꾼 중복 금지. 각 글은 버티컬·채널·각도가 달라야 함. 기존 대행사 판단 글(how-to-judge-agency-proposals 등)과는 내부링크로 연결, 중복 X.

### v2.1-E. 측정 (전환 키워드 순위)
추적 키워드 교체: 의료광고 심의류 → **동물병원 마케팅 업체 / 병원 블로그 대행사 고르는 법 / 홈페이지 제작 업체** 등 전환형. 4~8주 내 top-10 진입 = 전환되는 자리에서의 상위노출 = 진짜 증명.
