# AEO/GEO 글 작성 프롬프트 8단계 (대표 지정, 2026-10-04)

> 글을 쓸 때는 항상 아래 1→8 순서대로 진행한다. `page-building-workflow.md`의 단계·게이트와의 대응은 맨 아래 표 참고.
> 하우스룰(볼드 남발·AI 티 금지, 보장·근거 없는 숫자 금지 등)은 이 프롬프트보다 우선한다.

## 프롬프트 1: 검색 의도, 개요

당신은 15년 경력의 SEO 전략가이자 콘텐츠 기획 전문가입니다. 다음 메인 키워드에 대해 검색 의도를 분석하고, 그 의도에 최적화된 콘텐츠 개요를 작성해주세요.

메인 키워드: [메인 키워드]

[STEP 1] 검색자의 상황과 심리 분석
이 키워드를 검색하는 사용자의
- 현재 상황
- 해결하고 싶은 문제
- 궁금한 핵심 질문
을 구체적으로 설명하세요.

[STEP 2] SEO 콘텐츠 개요 작성
H1 ~ H3 구조로 실제 블로그 개요를 작성하세요. 이 때 꼭 리서치를 해서 실제 정보를 기반으로 작성하고 레퍼런스를 알려주세요.
형식: H1: H2: H3, H4는 꼭 필요한 경우에만 넣어주세요.
조건:
- 검색 의도를 가장 먼저 충족하는 구조로 작성
- AEO, GEO를 고려한 구조로 작성
- 불필요한 서론은 제외
- 실무자가 바로 글을 쓸 수 있도록 구체적으로 작성

## 프롬프트 2: H2, H3 정리

위 콘텐츠 개요의 H2, H3 소제목을 검토하고, GEO 기준으로 불필요한 섹션을 찾아주세요. 단, 소제목은 임의로 삭제하지 말고, 삭제 여부를 사용자에게 먼저 질문하세요.

[STEP 1] 소제목 진단
각 H2에 대해 아래 기준으로 평가하세요.
1. 검색자가 실제로 궁금해할 질문인가?
2. AI가 답변으로 사용할 수 있는 내용인가?
3. 문제 해결, 선택, 비교에 도움이 되는가?
→ 각 소제목을 다음 중 하나로 분류하세요. 유지 / 수정 권장 / 삭제 후보. 이유는 한 줄로 간단히 설명하세요.

[STEP 2] 삭제 여부 질문
삭제 후보로 판단된 소제목에 대해 다음 형식으로 사용자에게 물어보세요.
예시: 다음 섹션은 GEO 관점에서 활용도가 낮을 수 있습니다. 삭제할까요?
- H2: ○○○ 이유: AI가 답변으로 사용할 가능성이 낮음 / 서론 성격
→ 삭제 여부를 선택해주세요. (삭제 / 유지)
(사용자 답변을 기다립니다)

[STEP 3] 최종 구조 재정리
사용자의 선택을 반영하여
- 삭제된 소제목 제거
- 수정 권장 소제목은 질문 형태로 개선(필요한 경우)
- H2는 가능하면 검색자 질문 형태로 작성(필요한 경우)
출력 형식: 최종 구조 H1: H2: (H3, H4는 꼭 필요한 경우에만)

## 프롬프트 3: 콘텐츠 작성

위 개요를 기반으로 SEO + AEO/GEO를 고려한 블로그 초안을 작성해주세요.

[STEP 1] 콘텐츠 방향 확인
본문 작성 전에 사용자에게 다음을 질문하세요.
1. 이 글의 주요 목적은 무엇인가요? (브랜드 인지도 / 리드·문의 유도 / 제품·서비스 구매 또는 가입 유도 / 다른 콘텐츠로 이동 유도(내부 링크) / 기타)
2. 원하는 톤앤매너는 무엇인가요? (정보 중심·중립적 / 실무 경험 중심 / 친절한 설명형 / 개인 경험·후기 스타일 / 데이터 기반 / 기타)
3. CTA에서 유도하고 싶은 행동은 무엇인가요? (상담·문의 / 서비스 페이지 이동 / 다른 글 읽기 / 자료 다운로드 / 뉴스레터 구독 / 기타)
→ 사용자 답변을 받은 후 STEP 2를 진행하세요.

[STEP 2] SEO + EEAT 본문 초안 작성
1. AEO/GEO 구조
   - 각 H2 아래에 핵심 내용이나 결론을 먼저 제시하세요.
   - 명확하고 직접적인 문장으로 작성하세요.
2. EEAT 반영: 단순 정보 정리가 아니라, 다음 요소 중 해당되는 내용을 포함하세요.
   - 실제 경험 또는 사용 사례 / 관찰하거나 비교한 내용 / 상황별 설명 / 선택 또는 판단에 도움이 되는 정보 / 주의할 점 또는 한계
   (반드시 전문가 관점일 필요는 없으며, 실제 경험, 사례, 관찰 기반 내용이면 충분합니다.)
3. 모바일 가독성
   - 문장은 짧고 명확하게. 한 문단은 2~4줄 이내. 대부분 줄글 형태.
   - 인용구나 콜아웃은 필요할 때만 제한적으로. 이모지는 사용하지 마세요.
4. CTA 구성
   - STEP 1에서 설정한 목적에 맞게 글 흐름 속에 자연스럽게 CTA를 2~3회 배치하세요.
   - 광고처럼 보이지 않도록 정보 흐름 안에서 제안 형태로 작성하세요.
초안 작성할 때 반드시 웹검색을 해서 정확한 정보를 토대로 작성해주세요. 그리고 출처를 알려주세요.

## 프롬프트 4: 초안 다듬기

블로그 초안을 읽고, 다음 기준으로 평가하고 개선점을 제안해주세요.

검수 기준
1. 자연스러운 표현 — 어색한 표현, 번역체, 기계적인 문장이 없는지 확인. 있다면 수정 문장 제안.
2. 메시지 전달력 — 핵심 메시지나 관점이 명확한지 평가. 부족하면 보완 제안.
3. 정보의 충분성(검색 만족도) — 같은 검색어로 다른 글을 다시 찾을 필요가 없을 정도로 충분한지. 부족하면 추가 제안.
4. 독창성 — 단순 정보 정리에 그치지 않는지. 차별화를 위한 관점·설명·사례 제안.

추가 진단 — 경험 기반 콘텐츠(E-E-A-T)
실제 고객 질문 또는 고민 상담 / 세일즈·미팅 기반 사례 / 프로젝트 성과 데이터(수치 변화, 기간 등) / 의사결정 과정 또는 실패 경험 / 현장에서 반복적으로 발견한 인사이트
부족하다면: [경험 요소 보강] 추가하면 좋은 경험 자료: / 예시로 넣을 수 있는 상황:

출력 형식
[총평] 전반적인 완성도(상/중/하)와 이유
[항목별 피드백] 1. 자연스러운 표현(문제 문장/수정 제안) 2. 메시지 전달력(보완 필요 내용) 3. 정보의 충분성(추가하면 좋은 내용) 4. 독창성(개선 제안)
[경험 요소 보강] 추가하면 좋은 경험 자료 / 예시 상황
피드백을 반영하여 초안을 수정할까요? 원하시면 "수정해줘"라고 답해주세요.

(사용자가 "수정해줘"라고 답하면)
[STEP 2] 수정본 작성
- 제안한 개선사항 반영해 전체 글 재작성. 원래 구조(H1~H3) 유지.
- 문장은 더 자연스럽고 읽기 쉽게. 추가 정보는 흐름에 맞게. 중복·불필요 내용 정리.
- 문단은 2~4줄 이내. CTA 등은 수정하지 마세요.
출력 형식: [수정된 최종 초안]

## 프롬프트 5: AEO 구조

글의 내용은 수정하지 말고 구조만 업그레이드시켜주세요.
조건: AEO 구조 적용 — AI가 답변으로 활용하기 쉽도록, 내용 흐름을 해치지 않는 범위에서
- 중요한 내용은 결론 먼저 제시("결론:"이라고 표기하지 않기)
- 핵심 내용은 정리된 문장 혹은 불릿 리스트로
- 비교 또는 정리가 필요한 경우 표 사용
- 방법이나 절차는 단계형(번호 리스트)
- 필요한 경우 요약 또는 핵심 정리 블록 추가
※ 구조는 과도하게 추가하지 말고 자연스럽게 적용하세요.

이미지 가이드: 각 주요 섹션마다
[이미지 제안] 위치(예: H2 아래) / 유형(비교표·실제 화면·과정 다이어그램·체크리스트 등) / 목적 / SEO를 고려한 alt text
출력 형식: [수정된 최종 초안]

## 프롬프트 6: 타이틀, 디스크립션

당신은 SEO 전문가이자 CTR(클릭률) 최적화 카피라이터입니다. 위 블로그 초안 내용을 참고하여, 검색 의도에 맞으면서도 클릭을 유도할 수 있는 SEO 제목과 메타 디스크립션을 작성해주세요.
메인 키워드: [메인 키워드]
목표: SEO 노출과 함께 CTR을 높이는 것이 가장 중요. 글자 수는 너무 길지만 않으면 되며, 자연스럽고 읽기 쉬운 것이 더 중요. 메인 키워드는 제목 앞부분에 배치.

Title 기준: 각 제목에 최소 2가지 이상 포함
1. 검색 의도 반영(정보/추천/비교/방법 등) 2. 구체성(숫자, 대상, 상황, 기준 등) 3. 차별 포인트(실무 기준, 실제 사용, 정리, 핵심, 최신 등) 4. 호기심 또는 문제 해결 요소(선택 기준, 실패 방지, 중요한 포인트 등)
조건: 메인 키워드 앞부분 / 보조 키워드 자연스럽게 / 과장·낚시성 금지 / 초안 내용과 일치 / 서로 다른 스타일로 5개.

Meta Description 기준: 메인 키워드 자연스럽게 포함. 흐름 = 검색자의 상황 또는 문제 → 이 글의 핵심 내용 → 얻을 수 있는 도움. 간결하게(잘림 고려). 과장 광고 문구 금지.

출력 형식
1. Title: (포함 요소: 검색의도 / 구체성 / 차별 / 호기심) Description:
2. …

## 프롬프트 7: URL

메인 키워드: [메인 키워드] / 타이틀: [타이틀]
- 영어로, 단어 사이 하이픈(-), 짧고 간결하게, 불필요한 단어 제외, 메인 키워드 의미가 잘 드러나게.
- 총 3개 제안. 출력 형식: 1. /example-url 2. /example-url 3. /example-url

## 프롬프트 8: 롱테일 키워드

당신은 키워드 리서치 전문가입니다. 다음 기본 키워드를 기반으로 실제 검색량이 있을 법한 한국어 롱테일 키워드 50개를 생성하세요.
기본 키워드: [기본 키워드]
1. 실제 검색 환경 기준 — 네이버/구글 자동완성에 나타날 법한 표현, 대중적으로 많이 검색되는 형태
2. 길이 — 15~25자 이내, 2~5단어 수준의 짧은 검색 형태
출력 형식: 마크다운 표(| Keyword |). 표 아래 다음 줄에 50개를 쉼표로 구분해 한 줄로.
주의: 중복 금지, 불필요한 설명·작업 과정·자기 언급 금지, 결과만 출력.
