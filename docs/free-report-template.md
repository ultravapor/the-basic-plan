# 무료 진단 리포트 (한 장) — 템플릿

> 저위험 진입 오퍼. 신청자가 5문항에 답하면 이 형식으로 한 장짜리 리포트를 이메일 회신한다.
> 개인화(신청자 답 기반) + 일반 인사이트 + 가벼운 다음 단계. 현재는 대표가 직접 작성해 회신한다
> (영업일 2~3일 내). 강매하지 않는다. [master-strategy.md](master-strategy.md) PART 11·14·47 기준.

## 받는 5문항 (네이버 폼에 넣을 항목)
1. 병원명 · 지역(동/구) · 주요 진료
2. 현재 하고 있는 마케팅 (블로그 / 광고 / 플레이스 / 대행 등, 복수 가능)
3. 지금 가장 답답한 점 한 가지 (자유 서술)
4. 문의는 들어오는지 + 문의 대비 예약 체감 (좋음 / 보통 / 나쁨 / 모름)
5. 홈페이지 · 네이버 플레이스 · 블로그 URL (있으면)
+ 회신받을 이메일

## 리포트 구조 (한 장)

### 1. 이런 고민이시군요 — 개인화된 진단
- 신청자의 3·4번 답을 그대로 인용해 "지금 상태로 보면 발견 → 관심 → 비교 → 문의 → 응대 → 예약 중
  ○○ 단계에서 새고 있을 가능성이 큽니다"를 한두 문단으로.
- 단정하지 않는다: "가능성이 큽니다 / 신호가 보입니다"로. 보장·확정 금지.

### 2. 지금 직접 확인해볼 것 — 인사이트
- 그 병목 단계에 맞는 자가 점검 3가지 (예: 플레이스 통계 조회·전화·길찾기 / 서치콘솔 노출·CTR /
  문의 대비 예약률 데스크 기록).
- 해당 주제의 인사이트 글 1~2개 링크 (the-basic-plan.vercel.app/posts/...).

### 3. 혼자 어렵다면 — 다음 단계 (오퍼, 선택)
- "더 깊게 보려면 유입·전환 점검이 있습니다" 한 줄 + /checkup/ 안내.
- 강요하지 않는다. "지금 리포트만으로 내부에서 개선하셔도 됩니다."

## 톤 규칙
- 볼드 남발 금지, 보장 표현 금지, "안 해도 되는 것"도 함께 말한다.
- 개인화 부분(1)은 신청자 답에서만 끌어온다. 없는 사실을 지어내지 않는다.

## 퍼널
상세페이지(/checkup/·인사이트) → 무료 한장 리포트(개인화) → 유료 유입·전환 점검 / 마케팅 실행.
무료 리포트 = 리드 마그넷·관심 검증, 유료 점검 = 지불 의사 검증(마스터 PART 29·34).
