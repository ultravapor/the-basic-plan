# 점검 신청 인테이크 필드 (내부용)

점검 신청 폼이 받아야 할 최소 정보. 단순 연락처 수집이 아니라 진단에 필요한 재료를 받는다.
현재 신청은 네이버 폼(`SITE.naverFormUrl`)으로 연결되어 있으므로, 아래 항목을 네이버 폼에
반영하면 그대로 인테이크로 쓸 수 있다. (온사이트 폼으로 전환하려면 Formspree 등 엔드포인트 필요)

## 필수
- 병원명
- 지역(동/구까지)
- 주요 진료
- 연락 가능한 이메일 또는 연락처
- 현재 가장 답답한 점 (자유 서술)

## 선택 (있으면 진단 정확도↑)
- 홈페이지 URL
- 네이버 플레이스 URL
- 네이버 블로그 URL
- 현재 이용 중인 마케팅 (블로그/광고/플레이스/대행 등)
- 현재 대행사 이용 여부
- 최근 변화가 있었는지 (문의 감소·경쟁병원 신설 등)
- 문의는 들어오는지 (예/아니오/모름)
- 문의 대비 예약 전환 체감 (좋음/보통/나쁨/모름)
- 가장 확인하고 싶은 것 (자유 서술)

## 폼 설계 원칙
- 필드가 많아 전환이 떨어지면 단계형(필수 먼저 → 선택 나중) 또는 선택 입력으로.
- 개인정보를 불필요하게 수집하지 않는다.
- 마지막 화면 문구: "상담 전화로 영업하지 않습니다. 진단 결과를 글로 회신드립니다."
